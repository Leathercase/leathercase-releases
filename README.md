# Leathercase

**See your whole story.** Leathercase is a free desktop app that shows you the structure of your book (its scenes, threads and characters) over the files you already write in.

**[Download it at leathercase.app →](https://leathercase.app)**

This repository holds the installers and the update feed. The app's source is not here.

## Downloading

Get the app from [leathercase.app](https://leathercase.app): the page finds your system and offers the right build. If it can't, every file is on the [latest release](https://github.com/Leathercase/leathercase-releases/releases/latest).

| System | Builds |
|---|---|
| macOS 12+ | Apple silicon, Intel |
| Linux | AppImage and .deb, x86_64 and ARM64 |
| Windows | In testing; it will be on the site when it is ready |

Once installed, the app updates itself.

**Updating from a version before 0.30 on a Mac?** The app's identity changed in 0.30, so the updater cannot carry it across: download 0.30 once from [leathercase.app](https://leathercase.app). Windows and Linux update in place.

## Three promises

- **Your files, your computer.** Leathercase reads the files you write in and never changes them. What it adds is markdown and JSON beside your stories, readable without it.
- **No AI writing your book.** Connect your own assistant if you want one. You see everything it touches, and it never writes prose.
- **Free, for good.** No trial, no account, no locked features.

It reads Scrivener projects, Word documents, Markdown, Obsidian vaults and Fountain screenplays as they are.
