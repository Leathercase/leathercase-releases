Keys and commands ​

Every command Leathercase answers, with its key, where it works and what it does, then the keys each view answers while it is on screen, and how to change any of them. Keys are written for Windows and Linux; on macOS, use Cmd wherever this page says Ctrl, and Option for Alt.

Three ways reach every command:

  • its key, when it has one;
  • the menu bar (File, Edit, Story, View, Window), built from the same list, so the two never disagree;
  • the find field in the title bar (Ctrl+K): type part of a command's name and press Enter. The commands you used last come first.

To see the keys of the view you are in, press ? (when you are not typing in a field). A panel titled Keys of this view lists them; ? or Esc closes it.

Where a command works ​

Each command has a scope. A command outside its scope is not offered in the find field and does nothing when its key is pressed.

ScopeThe command works
AlwaysOn every screen, even before a writing home is open
With a home openOnce a writing home is open
With a story openWhile one of the home's stories is open in a view

A story view's command (Plot grid, Threads and the like) pressed when no story is open opens that view of the story you worked on last.

Menus and dialogs ​

A menu or dialog keeps its keys to itself: Esc closes it, and the view behind it takes no key while it is open. The agents menu in the title bar closes with Esc too.

Keys that work anywhere on this computer ​

Two keys can work even when another app is in front. They are off by default, so Leathercase takes no key from other apps until you ask.

KeyDefaultWhat it does
Capture to WriterCtrl+Shift+NOpens a small window over any app; what you type lands in the Writer's Ideas. In that window, Ctrl+Enter keeps it and Esc closes it
Show LeathercaseCtrl+Shift+SBrings Leathercase forward from any app

Turn them on in Settings › Hotkeys › Anywhere on this computer with Turn on global keys. To change one, click its key and press the new keys. If another app already holds a key, the row says so in amber, "Another app holds this key, so pressing it does nothing here", and you can pick another; if the system cannot hold it at all, it says "The system cannot hold this key." Turn off global keys gives them back to other apps. These two keys are kept in this computer's preferences.json.

Changing keys ​

Every command's key can be changed or removed in keybindings.json, a file in the app's data. Open it from Settings › Hotkeys with Edit keybindings.json; it opens in your text editor.

  • The file holds your changes only, and starts empty: { }. A key the app changes in a later version reaches you unless you overrode it.
  • Beside it, keybindings.defaults.json lists every command's id and default key, rewritten each time; copy a line from it.
  • Write one line per command: the command's id (shown in grey in Settings › Hotkeys), then its key. Write Mod for Ctrl (it becomes Cmd on macOS), and null to remove a key.
  • Leathercase reads the file the next time it starts.

For example, to give Characters a key and take Export off Ctrl+E:

json
{
  "go.characters": "Mod+Shift+C",
  "story.export": null
}

Settings › Hotkeys lists every command with its id and its key as it stands, so you can check the result.
